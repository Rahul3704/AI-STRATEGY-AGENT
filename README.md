# 🤖 AI Strategy Agent

An AI-powered strategy assistant that uses an **LLM through the OpenRouter API** to analyze critical situations and generate structured strategic responses.

## ✨ Features

* Enter a critical or complex situation
* AI analyzes the given scenario
* Generates a structured strategy and actionable considerations
* LLM-powered responses using OpenRouter API
* React-based interactive interface

## 🛠️ Tech Stack

**Frontend:** React
**Backend:** Node.js, Express.js
**AI:** LLM via OpenRouter API

## ⚙️ How It Works

```text
User Scenario
     ↓
React Frontend
     ↓
Node.js + Express API
     ↓
OpenRouter LLM
     ↓
Structured Strategy
     ↓
React UI
```

## 🚀 Run Locally

```bash
git clone <repository-url>

# Backend
cd backend
npm install
npm start

# Frontend
cd frontend
npm install
npm run dev
```

Add your OpenRouter API key in the backend `.env` file.

## 📌 Example

**Input:** A critical emergency situation requiring people to be protected.

**Output:** The AI provides a structured response covering objectives, priorities, risks, resources, and response considerations.
